# Memory Features

Engram's memory architecture for long-term context retention.

## Memory Types

### Episodic Memory

- Conversation sessions
- Turn-by-turn history
- Rolling window with summarization

### Semantic Memory

- Knowledge graph via Zep/Graphiti
- Facts with provenance
- Entity relationships

### Document Memory

- Ingested document chunks
- Tri-search indexing
- See [Document Ingestion Strategy](../../document-ingestion-strategy.md)
