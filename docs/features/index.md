# Engram Features

Engram provides a comprehensive set of features for enterprise AI interactions.

## Core Features

### 🎤 Voice Interaction

- Real-time bidirectional audio
- Azure VoiceLive integration
- Voice transcripts and enrichment
- [Voice Features](voice/)

### 💾 Memory & Knowledge

- Episodic memory (conversations)
- Semantic memory (knowledge graph)
- Sessions vs Episodes
- [Memory Features](memory/)

### 🔌 Connectors & Document Ingestion

- Data ingestion connectors
- **Document Ingestion with Tri-Search** (keyword, vector, graph)
- 5 source types: policies, tickets, PDFs, wikis, code
- Integration with external systems
- [Connectors](connectors/)
- [Document Ingestion Strategy](../document-ingestion-strategy.md)

### 📱 Mobile Features

- Visual art ingestion
- Structured document scanning
- [Mobile Features](mobile/)
